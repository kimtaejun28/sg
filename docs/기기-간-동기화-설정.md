# 기기 간 동기화 설정 안내

태블릿·PC·휴대폰 어디에서 접속해도 **같은 기록**을 보고 싶을 때 설정합니다.
설정하지 않으면 앱은 지금처럼 각 기기에만 저장되며, 그대로 사용해도 아무 문제 없습니다.

---

## 먼저 확인해 주세요 (중요)

이 기능을 켜면 **학생 실명과 행동 기록이 외부 서버(Supabase)에 저장됩니다.**

원래 이 앱은 "데이터는 반드시 로컬에만 보관한다"는 원칙으로 만들어졌습니다. 동기화는 그 원칙을
의도적으로 벗어나는 선택이므로, **학교의 개인정보 처리 규정을 먼저 확인**해 주세요.
많은 학교에서 학생 개인정보의 외부 클라우드 저장에 별도 절차를 요구합니다.

부담스럽다면 대안이 있습니다. 교사 페이지 → **데이터 백업** 탭에서 엑셀·JSON 파일을 내보내
다른 기기에서 불러오면, 실시간은 아니지만 같은 내용을 옮길 수 있습니다.

> 학생 실명 대신 별칭(예: "A학생", "1번")을 쓰면 위험을 크게 낮출 수 있습니다.

---

## 1. Supabase 프로젝트 만들기

1. [supabase.com](https://supabase.com) 접속 → 회원가입 (무료)
2. **New project** 클릭
3. 항목 입력
   - **Name**: 아무 이름 (예: `behavior-tracker`)
   - **Database Password**: 아무 비밀번호 (앱에서는 안 쓰지만 적어두세요)
   - **Region**: `Northeast Asia (Seoul)` 선택 — 가까울수록 빠릅니다
4. **Create new project** → 1~2분 기다립니다

## 2. 표 만들기

1. 왼쪽 메뉴 **SQL Editor** 클릭
2. 저장소의 [`supabase/schema.sql`](../supabase/schema.sql) 내용을 전부 복사해 붙여넣기
3. **Run** 클릭 → `Success` 가 나오면 완료

## 3. 로그인 계정 만들기

기록에 학생 이름이 들어가므로, **로그인한 사람만** 볼 수 있게 해야 합니다.

1. 왼쪽 메뉴 **Authentication** → **Users** → **Add user** → **Create new user**
2. 사용할 이메일과 비밀번호 입력
3. **Auto Confirm User** 를 **켜기** (메일 인증 절차를 건너뜁니다)
4. **Create user**

> 이 계정은 앱에 로그인할 때 쓰는 것으로, 교사 페이지의 4자리 비밀번호와는 별개입니다.

## 4. 접속 정보 넣기

1. 왼쪽 메뉴 **Project Settings** → **API**
2. 아래 두 값을 복사합니다
   - **Project URL**
   - **anon public** 키
3. 저장소의 `.env.example` 을 `.env` 로 복사한 뒤 값을 채웁니다

```
VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

배포 서비스(Vercel·Netlify 등)를 쓴다면 그 서비스의 **환경 변수** 설정에 같은 두 값을 넣고
다시 배포하면 됩니다.

## 5. 확인하기

1. 앱을 새로고침하면 로그인 화면이 나옵니다
2. 3번에서 만든 이메일·비밀번호로 로그인
3. 교사 페이지 → **데이터 백업** 탭 맨 위에 `다른 기기와 동기화됨` 이 보이면 성공입니다
4. 다른 기기에서 같은 주소로 접속해 같은 계정으로 로그인하면 같은 기록이 보입니다

## 알아두실 점

**로그인은 기기마다 한 번만** 하면 이후 유지됩니다.

**오프라인에서도 기록됩니다.** 인터넷이 끊기면 이 기기에 저장해 두었다가, 연결되면 자동으로
올라갑니다. 이때 상태 표시가 잠깐 `동기화에 실패했습니다` 로 바뀔 수 있지만 기록은 남아 있습니다.

**두 기기에서 동시에 기록하는 것은 피해 주세요.** 같은 순간에 양쪽에서 고치면 나중에 저장된
쪽이 남습니다. 기록은 한 기기(교실 태블릿)에서 하고 다른 기기에서는 확인·정리하는 방식을
권합니다.

**처음 연결할 때는 양쪽 기록을 합칩니다.** 기존에 각 기기에 쌓여 있던 기록이 사라지지 않도록
합쳐서 올립니다. 그 뒤부터는 삭제도 정상적으로 반영됩니다.

**동기화를 끄고 싶다면** `.env` 의 두 값을 비우고 다시 배포하면 됩니다. 기기에 저장된 기록은
그대로 남습니다.

**무료 플랜 한도**: 이 앱이 쓰는 양은 매우 적어(한 해 기록이 수천 건이어도 몇 MB) 무료 플랜으로
충분합니다. 다만 두 달 넘게 접속이 전혀 없으면 프로젝트가 일시 정지될 수 있으니, 방학 중에도
가끔 접속해 주세요.
