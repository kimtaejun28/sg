# 원 5차시 수업 자료 안내

도형 단원 '원'을 다섯 시간으로 진행하기 위한 자료 묶음입니다. 모두 빌드·설치 없이 브라우저로 열립니다.

| 파일 | 무엇 | 언제 |
| --- | --- | --- |
| `public/materials/circle-lessons/plan.html` | 5차시 수업 대본(지도안). 차시별 흐름·대본·판서·평가·오개념, 활동이 일찍 끝났을 때 쓸 이야깃거리 | 수업 준비와 진행 중 |
| `public/materials/circle-lessons/worksheets.html` | 학습지 5장 + 교사용 정답 2장(A4 인쇄용) | 1차시 2장, 나머지 차시 1장씩 |
| `public/materials/circle-hunt/index.html` | 동그라미 탐험대 — 그림 속 원 찾기 7단계 | 1차시 주 활동, 4차시 도입 |
| `public/materials/circle-parts/index.html` | 원의 한가운데 — 접어서 중심 찾기 / 지름 긋기 / 반지름과 지름 | 2차시 |
| `public/materials/circle-why/index.html` | 동그란 까닭 — 원을 쓰는 여섯 가지 까닭, 사례 24가지, 실험 2가지 | 5차시 |
| `public/materials/circle-lessons/why-guide.html` | 왜 하필 원일까 — 사례별 해설과 발문(교사용 설명 자료) | 5차시 준비 |

## 차시 구성

| 차시 | 주제 | 학생 준비물 |
| --- | --- | --- |
| 1 | 원 찾기와 본뜨기 | 종이, 연필, 색연필, 가위, 동그란 스티커 (동그란 물건은 교사가 바구니로 돌립니다) |
| 2 | 원의 중심·지름·반지름 | 1차시에 오려 둔 종이 원, 자, 색연필 |
| 3 | 컴퍼스로 원 그리기 | 컴퍼스, 자, 실 20cm |
| 4 | 원으로 무늬 만들기 | 컴퍼스, 자, 색연필 |
| 5 | 우리 주변의 원 — 동그란 까닭 | 연필 (교실 물건은 눈으로 찾음) |

1차시에 오려 낸 종이 원이 2차시 준비물이 되도록 묶어, 따로 챙길 준비물을 줄였습니다.

## 이동이 어려운 학생이 있는 학급

1차시 도입은 자리에 앉아서 하는 **'책상 위 보물 지키기'**입니다. 종이 한가운데 스티커를 붙여 보물로 삼고, 같은 길이 종이띠로 잰 자리에 점을 여덟 개 찍으면 원이 나타납니다. 손 조작이 어려우면 학습지 ①-1(점이 이미 찍혀 있어 색칠만 하면 됨)이나 칠판 자석 시범(학생은 방향만 말함)으로 대신합니다. 본뜨기용 동그란 물건도 교사가 바구니를 들고 돌면 자리를 뜰 일이 없습니다. 자세한 대안은 지도안 1차시 '모두가 참여하는 방법' 카드에 있습니다.

## 학습지 인쇄

`worksheets.html`을 열고 브라우저 인쇄(Ctrl+P / ⌘P)를 누르면 A4 7장으로 나옵니다. **1~5쪽이 학생용, 6~7쪽이 교사용 정답 모음**이니, 학생에게 나눠 줄 때는 인쇄 범위를 1~5쪽으로 지정하세요.
**배율 100%, 여백 없음**으로 두세요. 학습지 ①-1은 인쇄된 '보물 자'로 길이를 재는 활동이라 배율이 달라지면 자와 점의 거리가 함께 달라집니다(같은 종이에 인쇄되므로 배율이 바뀌어도 서로 맞습니다). 필요한 장만 인쇄하려면 인쇄 대화상자에서 페이지 번호를 지정합니다.

모든 문항의 정답과 예시 답안은 학습지 6~7쪽(교사용 정답 모음)에 정리되어 있습니다. 잰 길이는 원의 크기에 따라 달라지므로, 값이 아니라 관계(지름 = 반지름 × 2)와 까닭이 맞으면 정답으로 봅니다.

## 교실 네트워크가 불안할 때

여섯 파일 모두 단일 HTML이라 USB에 담아 가서 열어도 그대로 동작합니다. 웹폰트를 못 받아 오면 기본 글꼴로 표시될 뿐 기능은 같습니다.
