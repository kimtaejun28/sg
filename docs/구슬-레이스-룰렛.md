# 구슬 레이스 룰렛

이름을 넣으면 구슬이 코스를 굴러 내려가고, 먼저 결승선을 통과한 구슬이 당첨되는 추첨 웹 앱입니다.
같은 저장소의 별도 페이지(`/roulette.html`)로 동작합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173/roulette.html
npm run build    # dist/roulette.html 로 함께 빌드된다
```

## 기능

- **참가자 입력**: 한 줄에 한 명, 쉼표로도 구분.
  - `영희*3`, `영희/3` — 같은 이름 3개(최대 120개)
  - `영희#f43f5e` — 구슬 색 직접 지정. 개수와 같이 쓰려면 `영희*3#f43f5e`
  - CSV·엑셀 파일 불러오기(첫 열을 이름으로 읽고, 머리글 행은 버린다)
- **뽑는 방식 3종**
  - 앞에서 — 먼저 도착한 순서로 당첨자를 뽑는다. 정한 등수까지 도착하면 결과창이 뜬다.
  - 뒤에서 — 꼴찌부터 뽑는다. 끝까지 달린 뒤 결과가 나온다.
  - 팀 나누기 — 도착 순서대로 돌아가며 팀에 넣는다(1등 1팀, 2등 2팀…). 팀 인원이 자동으로 고르게 된다.
- **코스 4가지 선택**: 지그재그 / 핀볼 / 바람개비 / 랜덤(매 판 무작위, 어떤 코스인지 표시된다)
- **속도 ×1 ×2 ×4**, 일시정지, `결과 바로 보기`(남은 경기를 즉시 계산)
- **확대 보기**: 선두 구슬을 따라 붙어서 본다. 기본은 무리 전체가 보이도록 자동 축소/확대.
- **소리**: 파일 없이 WebAudio 로 만드는 충돌음·도착음. 끌 수 있다.
- **결과**: 순위·당첨자 복사, 결과 이미지(PNG) 저장, 설정을 담은 공유 링크
- **키보드**: 스페이스(시작·일시정지) / R(처음으로) / S(결과 바로 보기) / Z(확대) / M(소리), ESC 로 결과창 닫기
- **스크린리더**: 경기 시작, 상위 도착, 최종 결과를 `aria-live` 로 읽어준다

## 구조

```
roulette.html              페이지 진입점
src/roulette-main.jsx      React 마운트
src/roulette/
  RouletteApp.jsx          UI, 렌더 루프, 상태 관리
  participants.js          이름 파싱(`이름*3`), 공유 링크 인코딩
  engine/
    maps.js                코스 정의(벽/못/회전 막대/깔때기/결승선)
    sim.js                 planck(Box2D) 물리 시뮬레이션과 순위 판정
    renderer.js            캔버스 렌더링과 카메라
    audio.js               WebAudio 효과음
```

## 공정성과 안정성에 대해

- 출발 자리는 매 경기 무작위로 섞는다. 목록 순서가 유리·불리로 이어지지 않도록 하기 위함이다.
- 못과 벽 사이에 구슬이 끼면 최고 도달 지점이 갱신되지 않는 것으로 감지해서, 먼저 살짝 밀어보고
  그래도 안 빠지면 안쪽으로 조금 옮겨 준다(`sim.js` 의 구조 로직).
- 코스를 수정했다면 아래처럼 여러 판을 돌려 완주 여부와 소요 시간을 확인하는 것이 좋다.

```bash
node -e "import('./src/roulette/engine/sim.js').then(({Race})=>{
  for (const id of ['zigzag','pinball','pinwheel']) {
    let unfinished = 0, total = 0
    for (let s = 0; s < 20; s++) {
      const r = new Race(id, Array.from({length: 40}, (_, i) => i), s * 7919 + 1)
      if (!r.fastForward(240)) unfinished++
      total += r.time
    }
    console.log(id, '평균 완주', (total / 20).toFixed(0) + 's', '미완주', unfinished)
  }
})"
```
