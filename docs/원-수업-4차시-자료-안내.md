# 원 4차시 수업 자료 안내

도형 단원 '원'을 네 시간으로 진행하기 위한 자료 묶음입니다. 모두 빌드·설치 없이 브라우저로 열립니다.

| 파일 | 무엇 | 언제 |
| --- | --- | --- |
| `public/materials/circle-lessons/plan.html` | 4차시 수업 대본(지도안). 차시별 흐름·대본·판서·평가·오개념, 활동이 일찍 끝났을 때 쓸 이야깃거리 | 수업 준비와 진행 중 |
| `public/materials/circle-lessons/worksheets.html` | 학습지 4장(A4 인쇄용) | 차시마다 1장씩 |
| `public/materials/circle-hunt/index.html` | 동그라미 탐험대 — 그림 속 원 찾기 6단계 | 1차시 주 활동, 4차시 도입 |
| `public/materials/circle-parts/index.html` | 원의 한가운데 — 접어서 중심 찾기 / 지름 긋기 / 반지름과 지름 | 2차시 |

## 차시 구성

| 차시 | 주제 | 학생 준비물 |
| --- | --- | --- |
| 1 | 원 찾기와 본뜨기 | 동그란 물건 2개, 종이, 연필, 색연필, 가위 |
| 2 | 원의 중심·지름·반지름 | 1차시에 오려 둔 종이 원, 자, 색연필 |
| 3 | 컴퍼스로 원 그리기 | 컴퍼스, 자, 실 20cm |
| 4 | 원으로 무늬 만들기 | 컴퍼스, 자, 색연필 |

1차시에 오려 낸 종이 원이 2차시 준비물이 되도록 묶어, 따로 챙길 준비물을 줄였습니다.

## 학습지 인쇄

`worksheets.html`을 열고 브라우저 인쇄(Ctrl+P / ⌘P)를 누르면 A4 4장으로 나옵니다.
배율 100%, 여백 없음으로 두세요. 필요한 장만 인쇄하려면 인쇄 대화상자에서 페이지 번호를 지정합니다.

학습지 2번 4번 문제 정답: 가 ○, 나 ○, 다 ×, 라 × (다·라는 원을 가로지르지만 중심을 지나지 않는 선입니다.)

## 교실 네트워크가 불안할 때

네 파일 모두 단일 HTML이라 USB에 담아 가서 열어도 그대로 동작합니다. 웹폰트를 못 받아 오면 기본 글꼴로 표시될 뿐 기능은 같습니다.
